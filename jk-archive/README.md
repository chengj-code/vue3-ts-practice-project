# jk-archive 开发知识库

沉淀开发上下文与可复用经验，解决"开发完就忘、重复造轮子、重复踩坑"。

## 结构

```
jk-archive/
├── README.md        # 本说明
├── INDEX.md         # 知识总索引（含按标签检索）
├── sessions/        # 开发上下文档案（需求/方案/改动/问题，一次任务一份）
│   └── INDEX.md
└── patterns/        # 可复用模式/方案卡片（适用场景/要点/示例/坑）
    └── INDEX.md
```

## 用法

- **检索**：开始新任务前读 `INDEX.md` 按标签找，或直接问 AI"知识库里有没有 XX 的做法"
- **归档**：对 AI 说"归档 / 沉淀知识 / 保存开发记录"，按 jk-archive skill 流程执行
- **纪律**：先检索后新建，能复用/更新不新建；归档不复制全文，只留改动清单 + 摘要 + 关键片段
