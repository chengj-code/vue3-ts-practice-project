# 布局系统与 app store — 嵌套路由 + 可折叠布局壳 + 菜单动态生成 + UI 状态持久化

## 需求

spec Task 5（布局系统）+ Task 7 剩余（app store）：`DefaultLayout.vue` 三块结构（侧边栏可折叠 / 顶栏用户区登出 / 内容区 RouterView），菜单基于路由配置动态生成，`src/stores/app.ts` 侧边栏状态持久化（TR-7.2）。

## 方案

1. **路由骨架先行**：嵌套路由 `/` → DefaultLayout，children 挂业务占位页；meta 约定 `{ title, icon, hidden? }` 作为菜单数据源；`redirect: '/dashboard'`；`/login` 留位（Task 6）
2. **布局三块**：`el-container`（横向）→ `el-aside`（宽度绑定 isCollapse）+ 内层 `el-container`（纵向 el-header + el-main）；全局高度链 `html/body/#app { height: 100% }`
3. **菜单动态生成**：`router.options.routes` find（按 name）取 children → filter 掉 `meta.hidden` → v-for 渲染 `el-menu-item`；`router` 模式免手写跳转，`:default-active="$route.path"` 高亮跟随；`index` 用 `'/' + item.path`（children 是相对路径）
4. **折叠协同**：`el-aside :width` 与 `el-menu :collapse` 联动（collapse 固定 64px，aside 对齐 64px）；折叠按钮图标 Expand/Fold 表达"点击后动作"
5. **用户区**：`el-dropdown` + `@command` 收口（而非 horizontal el-menu，避免引入无意义的导航状态机）；登出 `clearUser()` + `push('/login')`
6. **app store**：`isCollapse` + 无参 `toggleCollapse`（取反语义），`persist: { pick: ['isCollapse'] }` 精确指定

## 遇到的问题与解决

| 问题 | 原因 | 解决 | 教训/可复用点 |
|------|------|------|--------------|
| `<component :is="'ArrowLeft'">` 图标不显示 | `:is` 字符串模式只解析全局注册组件/原生标签；编译期插件无法预测运行时字符串，不注入 import | 显式 import 图标，`:is` 传组件对象 | 动态组件一律传组件对象，不传字符串 |
| 菜单数据源 find 恒为空 | 误把 name（'layout'）当 path（'/'）匹配 | `item.name === 'layout'` 或 `item.path === '/'` | path 与 name 是两个字段，找路由先看清匹配依据 |
| iconMap 查不到，图标全落兜底 | map key（'dashboard'）与 meta.icon 值（'Odometer'）不同源 | key 与 meta.icon 的值严格同源 | 映射表的 key 必须以数据源字段值为准，单边维护 |
| `iconMap[item.meta.icon]` 报 unknown 不能作索引 | RouteMeta 自定义字段类型是 unknown（开放设计） | 模板 `as string` 断言（快修）；治本方案 `declare module 'vue-router'` 扩展 RouteMeta（未建，见待办） | meta 自定义字段建议声明合并定型，Task 11 权限前值得做 |
| 折叠后菜单文字仍显示 | el-menu collapse 隐藏文字的 CSS 选择器只认 `span`，裸文本节点匹配不到 | 文字包 `<span>` | 对照官方示例结构写，Element Plus 的 CSS 隐藏规则依赖固定标签 |
| logo 文字折叠时溢出 | logo 是自写 div，collapse 管不到 | `{{ isCollapse ? 'V' : 'Vue3 Admin' }}` | collapse 作用范围仅 el-menu 内部 |
| 折叠后右侧白边 | aside 宽度（100px）与 menu collapse 固定 64px 不对齐 | 两者都用 64px | collapse 模式菜单宽度是硬编码 64px |
| 顶部下拉用过重组件 | el-menu horizontal 模式做用户菜单，引入无意义 active 状态机（handleSelect 成死代码） | 换 el-dropdown + command 模式 | 导航用 menu，命令用 dropdown，语义选型 |
| ArrowDown 漏 import，type-check 绿但图标空白 | vue-tsc 对模板未解析组件默认宽松不报错 | 补显式 import | type-check 不是图标缺失的保险，要靠控制台 resolve 警告 |
