# T12 仪表盘 — EChart 封装组件 + 按需注册 + mock 统计联动

## 需求

任务书 T12：仪表盘页展示统计卡片 + 折线/柱状/饼图，数据来自 mock 接口，窗口 resize 后图表自适应（TR-12.1/12.2/12.3）。选型决策：不用 vue-echarts，原生 echarts + 自己封装（练生命周期管理）。

## 方案

- **按需引入**：`echarts/core` + 按需注册 3 图表 + CanvasRenderer + Grid/Tooltip/Legend/Title 组件，类型 `ComposeOption` 组合出 `ECOption`
- **EChart 封装**（src/components/EChart.vue）：props 只一个 `option: ECOption`；onMounted init（容器用 ref 不用 querySelector）、onBeforeUnmount dispose（先 observer.disconnect 再 dispose）；`watch(option, deep)` + `notMerge: true` 防旧 series 残留；**ResizeObserver 监听容器**而非 window.resize——侧边栏折叠只改容器宽度不触发 window resize；height prop 默认 320px（flex 子项不撑高）
- **注册位置演进**：初版全局注册在 main.ts → 发现 echarts/core 被拉进首屏主包（index 641KB）→ 挪进 EChart.vue 模块内（模块首次 import 时 use 一次，幂等），echarts 归入 Dashboard 路由 chunk，**主包 gzip 222KB → 22KB**
- **mock 联动**：仪表盘统计从用户列表共用 `allList` 实时算（新增/删除用户后仪表盘数字真实变化）
- 图表 option 用 computed 组装：数据 ref → computed → EChart watch 自动更新

## 遇到的问题与解决

| 问题 | 原因 | 解决 | 教训/可复用点 |
|------|------|------|--------------|
| 饼图图例静默消失 | 全局注册漏了 LegendComponent | 补注册 | echarts 漏注册组件不报错，对应部分静默不渲染 |
| 全量 `import * as echarts` 把 chunk 撑到 532KB | 占位页遗留的全量导入 | 换封装组件（echarts/core 按需） | 全量导入是体积黑洞，library/core + use 是标准姿势 |
| 首屏主包 641KB（gzip 222KB） | echarts.core 全局注册在 main.ts 入口依赖图 | 注册挪进 EChart.vue，echarts 归入路由 chunk | 全局注册第三方库会把库拽进首屏；组件内聚注册 = 天然分包 |
