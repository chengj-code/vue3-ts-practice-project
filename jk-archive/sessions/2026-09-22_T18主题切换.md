# T18 主题切换 — 明暗 + 品牌色的 CSS 变量体系收口

## 需求

任务书 T18：明暗模式切换 + 品牌主题色切换，全局实时生效、刷新保持（TR-18.1/18.2/18.3）。项目现状是「暗色写死在 `:root` + `index.html` 写死 `class="dark"`」。

## 方案

**核心架构**：品牌色唯一源头 `--brand-color`，EP 主色全套（light-3/5/7/8/9、dark-2）与 `--console-accent` 全部用 CSS `color-mix()` 动态派生——JS 换品牌色只 `setProperty` 这一个变量，全局联动。

- store：`theme: ref<'light'|'dark'>('dark')` + `primaryColor` + `toggleTheme`，`persist.pick` 显式加两项
- FOUC：`index.html` head 内同步 IIFE 读 `localStorage('app')`（pinia persist 的 key = store id），Vue 挂载前挂 class 和 `--brand-color`
- 同步：App.vue 两个 `watchEffect`（立即执行 + 自动追踪，把响应式状态同步到 Vue 管不到的外部世界：html class、CSS 变量）
- 变量分层：亮色 `:root:root`（0,2,0），暗色 `:root.dark`（0,2,0 同级、源顺序在后取胜）
- 固定暗色页（登录/403）：页面局部 Token 不参与切换，根元素锁回一组 EP 暗色变量防「暗页亮组件」
- 图表：canvas 不继承 CSS 变量 → 色值按 `isDark` 在 JS computed 重算 → option 重算 → EChart 组件 watch 自动 setOption；图表主色直接绑 `primaryColor`

## 遇到的问题与解决

| 问题 | 原因 | 解决 | 教训/可复用点 |
|------|------|------|--------------|
| 亮色下主按钮变 EP 默认蓝 | EP 按需样式分 chunk 加载，其 `:root` 默认蓝晚于 main.css 出现，同特异度靠顺序被打回 | 亮色块改 `:root:root` 提特异度 | 按需引入的组件库样式加载顺序不可控，覆盖变量必须提特异度 |
| 半亮半暗精神分裂状态 | `:root:root`(0,2,0) 反压了 `html.dark`(0,1,1)，暗色同名变量被亮色块赢走一半 | 暗色块改 `:root.dark` 同级 + 源顺序在后 | 提特异度不能只提一边：同一批变量多作用域竞争时，各作用域特异度必须有序 |
| 亮色下按钮深绿字配中绿底显脏 | 暗色的「亮底深字」规则照搬到了亮色（中明度底） | 深字规则限定 `:root.dark`；品牌色换 600 档保证白字对比 | 按钮文字色方案取决于「底色的明度档」，不是所有主题都一套规则 |
